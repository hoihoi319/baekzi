# 백지 (Blank Slate)
### 내가 가르친 것만 아는 AI 제자 · v1

학생이 AI를 가르치는 학습 도구. 제자는 학생이 말해 준 규칙만으로 시험을 봅니다.
아는 척을 못 하므로, 제자가 틀리면 그건 **학생의 설명에 뚫린 구멍**입니다.

---

## 바로 실행

`blank-slate.html` 을 **더블클릭**하세요. 설치·서버·인터넷 없이 브라우저에서 바로 열립니다.
단일 파일이므로 USB로 옮기거나 메일로 보내도 그대로 작동합니다.

권장 환경 — 태블릿 가로(1024px 이상) 또는 데스크톱 브라우저(크롬·사파리·엣지 최신).

## 5분 시연 (자세한 대본은 기획의도 문서 3부)

1. 열면 **온보딩 3장**이 뜹니다. 넘기거나 건너뛰세요.
2. 개념은 **분수 나눗셈**으로 시작.
3. 제자에게 이렇게 가르칩니다 → `분수 나눗셈은 뒤집어서 곱하면 돼.`
4. **시험 보기**를 누릅니다.
   → **계산 5/5 · 의미 0/3 · 설명 0/2**. 여기가 핵심 장면입니다.
5. 이어서 가르칩니다 → `나눗셈은 똑같이 나눠 주는 거야. 피자 반 판을 세 명이 나눠 먹는 것처럼.`
6. 다시 시험. **맞던 문제가 틀립니다** — 회귀. 불완전한 개념이 작동하던 절차를 막습니다.
7. 고치는 문장 → `6 안에 1/2이 몇 번 들어가는지 세는 것도 나눗셈이야.`

36개 문장 전체 정답지는 기획의도 문서 **2부**에 있습니다.

## 두 가지 모드

화면 오른쪽 위에서 전환합니다.

- **학생 모드** — 큰 글씨, 44px 터치 영역, 쉬운 말. 점수·석차 표기 없음. AI 연결 숨김.
- **교사 모드** — 조밀한 정보 밀도, 전문 용어, 로그 내보내기, AI 연결.

같은 코드 한 벌에 밀도 토큰(`data-density`)과 말 바꾸기 사전(`tw()`)만 다르게 적용됩니다.

## AI 연결 (선택 사항 · 교사 모드 전용)

기본은 **규칙 모드**입니다. AI 없이 완전히 작동합니다.

AI를 붙이면 "맥락상 맞는 다른 표현"을 받아 줍니다. 이때도 **AI는 제자가 아닙니다.**
AI는 학생 문장에 어떤 슬롯 내용이 들어 있는지만 판정하는 **추출기**이고,
제자의 추론은 그대로 결정론적 규칙 엔진입니다. — *유연한 귀, 엄격한 머리.*

지원하는 연결 (**유료 API 경로 없음**):

| 방식 | 비고 |
|---|---|
| **Ollama** (로컬) | 권장. 문장이 기기 밖으로 나가지 않음 |
| **LM Studio** (로컬) | 권장 |
| **Gemini 무료 등급** | 인터넷 필요 |
| 직접 입력 | OpenAI 호환 `/chat/completions` 엔드포인트 |

**로컬 모델을 기본으로 권장합니다.** 비용 때문이 아니라, 학생이 개념을 설명하며 쓴 문장은
성적표보다 민감한 자료이기 때문입니다. 키는 브라우저 탭 메모리에만 있고 저장되지 않습니다.
